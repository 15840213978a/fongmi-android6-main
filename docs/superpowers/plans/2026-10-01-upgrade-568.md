# 5.6.8 upgrade plan

Goal: upgrade the existing Android 6 fork to real 5.6.8 code and dependencies,
with Android 7 as the new minimum, as authorized by the user.

Architecture: use the pinned, previously successful source tree and Media3
pipeline. Preserve the target repository's installed application identity,
signing key and updater UI. Build on an isolated branch and publish prereleases.

1. Compare source, modules, workflows and installation identity. Done.
2. Prepare source import, updater overlays and adapted build workflow.
3. Check XML, migration 35 -> 36 and workflow syntax locally.
4. Push the branch; run the real four-APK CI build and inspect artifacts.
5. Review the final diff and open a draft PR with validation and device limits.

Decisions: Android 6 compatibility is explicitly dropped. Existing stable
releases and main are retained. No new signing key is generated. The old
branch's debugging and shell-proxy changes are not part of the 5.6.8 baseline.
The source repo's GoProxy bad-ELF guard is retained.
